Mini Bivert Module for Game Boy

Status: active · Published Oct 1, 2018

  • game boy
  • lcd
  • modding
  • pcb
  • retro hardware

The Mini Bivert Module is a small PCB I designed for the classic Game Boy bivert display upgrade. The goal was to make the installation cleaner, especially in DMG and Pocket consoles where the available space is always part of the challenge.

A bivert circuit is not huge, but wiring it neatly by hand every time gets old quickly. A dedicated board makes the connections more controlled, reduces the chance of mistakes, and gives the installation a more finished feel.

This is the kind of project I enjoy because it is very focused. It takes one common screen-related task and makes it smaller, cleaner, and easier to repeat.

It also fits well with my wider Game Boy hardware work.
