Little PnP

Status: active · Published Dec 1, 2014

  • electronics
  • robotics
  • open hardware
  • smt
  • 3d printing
  • automation

Little PnP is my open-source attempt at solving a very real workshop problem: assembling small runs of SMT boards without depending on a full external assembly process every time I want to test an idea.

The project mixes mechanical design, electronics, 3D-printed parts, motion control, software, and a bit of stubbornness. A pick-and-place machine looks simple from the outside, but once you start building one you quickly find all the small details that matter.

For me, Little PnP is not only about the machine itself. It is also about the workflow around it: PCB design, prototypes, components, preparation, and repeatable assembly.

It connects with other private tools I use for inventory and parts management, because automation only works well when the surrounding process is also organized.
