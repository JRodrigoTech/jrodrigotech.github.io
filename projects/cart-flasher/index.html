Cart Flasher for Game Boy

Status: active · Published Nov 1, 2016

  • game boy
  • retro hardware
  • electronics
  • cartridge programmer
  • embedded tools

The Cart Flasher is one of the projects I have spent the most time around in the Game Boy hardware world. It is a small board, but it solves a very useful problem: talking to a Game Boy cartridge from a modern computer.

With it, I can dump ROMs, back up saves, write saves back to cartridges, and program compatible flash cartridges. That sounds straightforward, but the interesting part is all the small hardware and software details needed to make the process reliable with real cartridges.

I built this because I wanted a practical tool for development, testing, preservation, and my own flash cartridge work. When you are working with retro hardware, having a dependable programmer changes the whole workflow. You stop treating cartridges as closed objects and start treating them as hardware you can inspect, back up, and reuse.

The Cart Flasher also connects many of my other Game Boy projects: FRAM cartridges, mapper logic, cartridge adapters, and save-management workflows. It is a very good example of the kind of project I like: small enough to fit on a bench, technical enough to be interesting, and useful enough that it keeps coming back into the workflow.
