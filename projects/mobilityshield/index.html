Mobility Shield - Open-Hardware Robotics Platform

Status: archived · Published May 21, 2014

  • robotics
  • open hardware
  • 3d printing
  • parametric design
  • web tool

Mobility Shield was one of my early open-hardware robotics projects. The idea was simple: instead of publishing a fixed set of robot parts, I wanted to make a system where the parts could adapt to the builder.

That led to MS Builder, a browser-based tool for generating custom STL files from parametric designs. You could adjust dimensions, generate the part, and print it.

The project mixed robotics, 3D printing, web tooling, and mechanical design. It also taught me a lot about documentation, compatibility, naming, examples, and making sure people can actually understand what they are downloading.

Mobility Shield is archived now, but I still see it as an important project in my timeline.
