PromptFlow - Local Prompt Manager for Chrome

Status: active · Published Apr 1, 2026

  • chrome extension
  • local-first
  • productivity
  • ai workflow
  • javascript

PromptFlow is a Chrome extension I built to make reusable prompts easier to manage. The idea is simple: save prompts locally, give them short names, and insert them anywhere in the browser with a // shortcut.

I made it because I was repeating the same prompt structures again and again. Some were for coding, some for writing, some for analysis, some for client-style work. Keeping them in random notes or old chats worked for a while, but it became messy quickly.

PromptFlow keeps the workflow close to where I am already writing. When I type //, the extension can show matching prompts, filter them, and insert the full text without opening another tool. It also supports tags, search, and JSON import/export, so the library can be backed up or moved between Chrome profiles.

The local-first part matters to me. Prompts stay in Chrome local storage; there is no account, no external prompt database, and no cloud dependency for the basic workflow. It is a small productivity tool, but it solves a real daily annoyance: keeping useful writing and AI workflows close without turning them into another platform to manage.
