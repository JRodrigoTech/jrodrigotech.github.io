FTDI Breakout USB-to-UART Board

Status: active · Published Jan 1, 2018

  • usb
  • uart
  • ftdi
  • embedded systems
  • electronics

This FTDI breakout is one of those bench tools that is not very glamorous, but you end up using all the time. It is a USB-to-UART board based on a genuine FT232RL, with selectable 5 V or 3.3 V logic levels.

I made it because serial adapters are part of almost every embedded workflow: programming boards, reading logs, debugging firmware, checking boot messages, or just talking to a microcontroller from a terminal.

The board exposes the useful UART signals, includes basic USB-side protection, and keeps the voltage selection clear. Nothing exotic, just the kind of practical details that make a tool nicer to use on a real electronics bench.

For me, this project belongs to the category of small infrastructure. It tries to remove friction from the next project.
