Game Boy FRAM Cartridges

Status: active · Published Mar 1, 2016

  • game boy
  • cartridge
  • fram
  • cpld
  • retro hardware

These cartridges are part of my Game Boy hardware work. The idea is to have programmable cartridge hardware for homebrew, testing, development, and retro hardware tinkering without depending on old battery-backed save circuits.

The boards use rewritable memory for program data and FRAM for saves. I like FRAM for this kind of project because it keeps the save data without needing the usual battery-backed SRAM approach.

A lot of the interesting work is hidden in the details: memory layout, mapper behavior, board routing, shell fit, programmer compatibility, and making sure the cartridge behaves properly on real Game Boy hardware.

This project ties directly into my Cart Flasher and MBC5 mapper work.
