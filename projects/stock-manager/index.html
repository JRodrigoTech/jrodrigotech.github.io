Stock Manager - Private Workshop Inventory System

Status: active · Published Jan 1, 2019

  • private tool
  • inventory
  • php
  • mysql
  • automation
  • barcodes

Stock Manager is a private tool I built because component inventory gets messy very quickly when you work with electronics for long enough. Resistors, ICs, connectors, modules, PCBs, screws, labels, boxes… everything looks manageable until you actually need to find one specific part fast.

The application tracks components, quantities, purchases, storage locations, usage, and barcode labels. It is not meant to be a generic ERP. It is a workshop tool built around the way I actually store and use parts.

For me, the interesting part is how it connects the digital side of the workshop with the physical one. A part in a database is only useful if I can find the real box. A barcode is only useful if it reduces friction instead of adding another ritual. The system has to stay practical or it will not be used.

It also connects naturally with Little PnP and small-batch PCB assembly. If a machine is going to place components, the inventory around that machine needs to know what exists, where it is, and what has been consumed. Stock Manager is one of those quiet projects that supports many other projects behind the scenes.
