Stock Manager - Private Workshop Inventory System

Status: active · Published Jan 1, 2019

  • private tool
  • inventory
  • php
  • mysql
  • automation
  • barcodes

Stock Manager is a private tool I built because component inventory gets messy very quickly when you work with electronics for long enough.

The application tracks components, quantities, purchases, storage locations, usage, and barcode labels. It is not meant to be a generic ERP. It is a workshop tool built around the way I actually store and use parts.

For me, the interesting part is how it connects the digital side of the workshop with the physical one. A part in a database is only useful if I can find the real box.

It also connects naturally with Little PnP and small-batch PCB assembly.
